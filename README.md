# 几何小老师

一个初中平面几何辅导 Skill：大画板、自由书写、撤销，以及跟着图形一步一步看的提示。先支持等腰三角形和全等三角形。

**安装后，对你的 AI Agent 说：**

> 几何小老师

或者直接把题目发给它：

> 几何小老师，讲这道题：在△ABC中，AB=AC，∠BAC=80°。求两个底角。

Agent 负责启动、构图和检查依据；孩子选择学过的知识，先自己画一画，做不出来时再点“给我一点提示”。不需要孩子理解命令或文件格式。

## 安装一次

把本仓库交给支持本地 Skill 的 Agent，请它安装 `junior-geometry-tutor`。也可以从 [Releases](https://github.com/heimu-liu/junior-geometry-tutor/releases/latest) 下载统一安装包，使用宿主的本地 Skill 导入能力；支持目录安装的宿主加载包含 `SKILL.md` 的根目录。

WorkBuddy、Codex、Claude Code 等使用同一份 Skill，不分平台安装包。需要 Python 3.10+、现代浏览器，以及 Agent 的文件读写和终端能力；Python 脚本只依赖标准库。不需要 MCP。

**目前实测的是 Codex 本地流程。WorkBuddy 客户端导入与其他 CLI 账号调用还未实测。** 通用文件交接模式下，在画板提交新题后对 Agent 说“讲这道题”；已配置的自动模式不需要这一步。

## 做题时会发生什么

1. 选择年级、教材和真正学过的知识。
2. 输入题目，模型提出构造与解题计划。
3. 本地程序计算题图、核对每一步的定理前提；未通过的解法不显示。
4. 先自由思考，再逐步展开问题、小提示和解释；辅助线、对应颜色、角度跟着变化。
5. 保存学习记录，之后继续。手写笔迹与教学图层分开，支持撤销/重做。

模型负责理解与规划；程序负责构图和已支持定理的校验。提示展开由本地执行，不是每点一步都重新请求模型。

## 能力范围

- 等腰性质与逆定理、等边定义、三角形内角和、中点与角平分线定义。
- SSS、SAS、ASA、AAS、HL，以及全等后的对应边/角；拒绝 SSA/AAA、缺前提、错误对应和循环证明。
- 本地中点、垂足、交点、反射与按边长/角度构图。有理数尽可能精确；开方/三角函数使用经检查的浮点。
- 方法受明确勾选的知识限制。年级/教材/章节尚未自动映射，“全等”暂未细分到只学过某一种判定。
- 图片可放到画板里；自动通道目前处理文字，不自动识别照片。题库与扩展练习后续再加。

这是有限定理内核，不是所有初中几何题的通用证明器。题意提取仍需核对；只有一条可靠解法时不凑多解。
